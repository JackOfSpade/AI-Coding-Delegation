## Offload

`offload` is available when the user invokes `/offload`, asks to offload/delegate, or names DeepSeek/DeepSeek-V4-Pro, as well as for clearly bounded multi-file implementation, testing, or debugging work. Follow the `offload` skill before using its MCP tools. By default, route worker packages through `mcp__offload__offload_start` with the configured profile `pro` (the provider-maintained current DeepSeek Pro route, high effort) and omit `effort`; an explicitly selected supported profile name overrides that default. Never invent a generic “latest Pro” model name: a future major model ID or pricing change requires a trusted package/config update. Workers can edit their permitted files in a private linked worktree with file tools even on a policy-only host, but have no worker shell there; primary Claude reviews the diff and runs verification before its final answer. Never use Claude Code native subagents. Keep architecture, security decisions, integration, and final review with the primary agent; respect a user request to work solo. A model name in a task is a routing trigger, not permission to infer a profile.
